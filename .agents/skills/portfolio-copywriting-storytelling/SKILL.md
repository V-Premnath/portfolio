# Portfolio Copywriting & Impact Storytelling

The Copywriting & Storytelling skill transforms raw resume bullet points into compelling narratives that showcase technical depth, problem-solving prowess, and measurable business impact.

<HARD-GATE>
Do NOT use generic boilerplate copy, filler text, or vague clichés (*"passionate problem-solver who writes clean code"*). Every featured project MUST include a concrete problem statement, technical rationale, and quantifiable metrics before integration into the UI.
</HARD-GATE>

---

## 1. Copywriting Principles

1. **Quantify Everything**: Technical recruiters and engineering managers evaluate impact through numbers (latency reduction, traffic scale, cost savings, user growth, uptime).
2. **Show, Don't Just Tell**: Instead of saying *"expert in performance"*, describe *"reduced initial page payload from 4.2MB to 180KB using tree-shaking and dynamic WebP pipelines"*.
3. **Conversational Authority**: Write with confidence, clarity, and precision. Avoid defensive language or self-deprecating disclaimers.
4. **Scannable Hierarchy**: Readers scan before they read. Use bold lead-ins, bulleted metrics, and badge tags for quick consumption.

---

## 2. Anti-Patterns & Red Flags

| Red Flag / Mental Shortcut | Reality | Correct Action |
| :--- | :--- | :--- |
| *"I'll just paste their job descriptions verbatim."* | Job descriptions describe duties, not personal achievements or technical breakthroughs. | Reframe achievements using the STAR methodology (Situation, Task, Action, Result). |
| *"Lorem Ipsum or 'Project title coming soon'."* | Placeholders break the visual composition and make portfolios feel abandoned. | Generate realistic, authentic project stories based on user inputs. |
| *"A huge 8-paragraph biography detailing childhood hobbies."* | Visitors bounce if they can't determine what you build within 5 seconds. | Limit the bio to 3 tight paragraphs focused on current focus, engineering philosophy, and human touch. |

---

## 3. Implementation Workflow

1. Review the projects gathered during the Discovery Phase (`portfolio-discovery-strategy`).
2. Consult the [Case Study Framework Reference](./references/case-study-framework.md).
3. Draft:
   - **Hero Tagline & Subheading**: High-impact value proposition + Availability Status Badge.
   - **Flagship Project Deep-Dives**: Context, Technical Architecture, Key Trade-offs, and Quantified Results.
   - **Bio / About Narrative**: Engineering philosophy, current tech stack mastery, and personal interests.
   - **Contact Section Copy & Microcopy**: Clear CTA invitations, email copy triggers with feedback tooltips, and response time guarantees (e.g., *"Typically replies within 24 hours"*).
4. Review copy with the user for tone alignment and factual accuracy.
